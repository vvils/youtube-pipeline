YouTube Pipeline

Privacy policy

Effective 1 November 2026.

YouTube Pipeline is a personal command-line tool. Its owner (GitHub user vvils) uses it with their own YouTube channels. It is not offered to anyone else.

What it accesses

When the owner signs in with Google, the tool asks for three permissions:

  • Manage the YouTube account (youtube.force-ssl): Google describes this permission as seeing, editing and permanently deleting the account's videos, ratings, comments and captions. The tool uses it to read the channel's ID, name and handle, so a video always goes to the channel the owner meant; to list the channel's latest uploads with their privacy, length and views; to upload videos and thumbnails; to edit an uploaded video's title, description and other details; and to change a video's privacy or schedule when it goes public. It never deletes anything, and never reads, writes or rates comments, ratings or captions.
  • View YouTube Analytics reports (yt-analytics.readonly): to read, for the owner's own videos, views and engaged views, watch time and how much of each video was watched, counts of likes, shares, comments and subscribers gained, and audience retention (where viewers stopped watching). It reads the counts, not the comments themselves.
  • View monetary YouTube Analytics reports (yt-analytics-monetary.readonly): to read estimated revenue for the owner's own videos, alongside the figures above.

How the data is used

The data is used only to publish the owner's videos and to learn how they performed and where viewers stopped watching, so the next video is better. It is not sold, not shared with anyone, not used for advertising, and the owner does not use it to train any AI model.

Where it is stored

Sign-in tokens stay on the owner's computer. Each video's figures are saved with that video's production records, on the owner's computer and in the owner's private GitHub repository. The tool has no hosted server and no database of its own. The owner may run the tool through an AI coding assistant on that computer, which reads the tool's output while working, so that output passes through the assistant's provider. Beyond these, the tool sends data nowhere except Google's own APIs.

Removing access

Access can be withdrawn at any time from Google Account: third-party connections, which invalidates the stored tokens. The owner can also delete the token files on their computer.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Its use of information received from Google APIs follows the Google API Services User Data Policy.
