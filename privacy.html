YouTube Pipeline

Privacy policy

Effective 31 October 2026.

YouTube Pipeline is a personal command-line tool. Its owner (GitHub user vvils) uses it with their own YouTube channels. It is not offered to anyone else.

What it accesses

When the owner signs in with Google, the tool asks for three permissions:

  • Upload videos (youtube.upload): to upload the owner's videos and thumbnails to the owner's channel.
  • View the YouTube account (youtube.readonly): to read the channel's ID, name and handle, so a video always goes to the channel the owner meant, and to read a video's length.
  • View YouTube Analytics reports (yt-analytics.readonly): to read views, watch time and audience retention for the owner's own videos.

How the data is used

The data is used only to publish the owner's videos and to learn which parts of them viewers watched, so the next video is better. It is not sold, not shared with anyone, not used for advertising, and not used to train any model.

Where it is stored

Sign-in tokens and analytics files stay on the owner's computer. The tool has no server and no database, and it sends data nowhere except Google's own APIs. The owner may run the tool through an AI coding assistant on that computer, which reads the tool's output while working.

Removing access

Access can be withdrawn at any time from Google Account: third-party connections, which invalidates the stored tokens. The owner can also delete the token files on their computer.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Its use of information received from Google APIs follows the Google API Services User Data Policy.
